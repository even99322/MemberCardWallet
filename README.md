# 會員卡夾 MemberCardWallet

把各家店的會員條碼集中在一個 Android App 裡，結帳時打開就能給店員掃。

## 功能

- **新增會員卡**
  - 相機掃描實體卡或別人手機上的條碼
  - **從截圖辨識**：在店家 App 裡截圖會員條碼，選這張圖就會自動讀出號碼與格式
  - 手動輸入號碼
- **記帳**：支出／收入／轉帳；計算機鍵盤（可 + − 計算）、分類圖示、常用備註、日期、帳戶選擇
  - 明細：每月支出／收入／結餘、預算進度、依日期列出
  - 圖表：分類甜甜圈圖、每日甜甜圈圖、每日趨勢圖、分類排行
  - 帳戶：淨資產、資產／負債，現金／銀行／信用卡／虛擬帳戶餘額
  - 自訂分類、匯出 CSV（Excel 可開）
- **LINE Pay 自動記帳**：開啟通知存取權後，讀取 LINE Pay 付款通知自動記下金額與商家並分類；無法辨識的通知會留在擷取紀錄，可一鍵補記（也可選擇記錄快捷列上其他付款 App）
- **拖曳排序**：首頁「⇅ 排序」可拖動調整卡片順序（全部或單一資料夾）與資料夾順序
- **刷卡記錄位置**：刷卡、付款自動記帳時同時記下消費地點（GPS＋地址），記帳明細顯示地址、點一下開地圖；圖表頁有「消費地點」排行；手動記帳也可加入目前位置（需位置權限「一律允許」，位置只存在手機）
- **記帳桌面小工具**：本月支出／收入／結餘，「＋支出」「＋收入」一鍵記帳，顏色跟著主題
- **Google 雲端備份**：備份到 Google 雲端硬碟（卡片、照片、記帳、設定全包），可每天自動覆寫，從雲端還原
- **信用卡刷卡通知記帳**：選擇銀行 App、Google 錢包等通知來源，刷卡通知自動記帳
- **寄杯／多次券**：票券可設份數，每次「使用一份」自動扣，用完自動移到已使用
- **票券夾**：優惠券、兌換券可設到期日、標記已使用，已用／過期自動淡化排到最後
- **提醒通知**：卡片／票券快到期、定期收支明天扣款、支出達預算 80%／超支
- **一句話記帳＋語音**：輸入或說「午餐 120」「加油 1500 信用卡」自動判斷分類、金額、帳戶
- **App 圖示長按捷徑**：「記一筆」「載具條碼」與常用卡片
- **分享卡片**：把會員卡或票券分享給家人，對方用會員卡夾一鍵匯入
- **自動點到條碼頁**：動態條碼 App 可設定（或錄製）點擊步驟，從會員卡夾開啟時自動點到會員條碼畫面（需開啟無障礙權限；條碼仍只在原 App 中顯示，不會被擷取）
- **定期收支**：訂閱、房租、薪水每月固定日期自動記一筆
- **記帳搜尋與分析**：跨月份搜尋、近 6 個月趨勢、與上月比較、花最多的項目
- **桌面小工具與快速設定磚**：手機條碼載具、電話直接放在桌面或通知列，一點全螢幕
- **點數／餘額、實體卡照片**：每張卡記錄點數與更新時間；拍下實體卡正反面
- **快捷列**：首頁最上方顯示手機條碼載具、多組電話號碼（主要＋備選，點一下全螢幕放大並可切換）、常用付款 App（一鍵開啟），可收合
- **7 種介面主題**：科幻 HUD、霓虹賽博、終端機綠、經典深色、簡約淺色、莫蘭迪、櫻花粉（設定 → 顯示 → 外觀主題）；可切換卡片格狀／精簡清單
- **App 鎖定**：指紋、臉部或螢幕鎖解鎖，離開超過 30 秒自動上鎖
- **全螢幕條碼**：點條碼放大成全螢幕（一維條碼自動轉橫向），方便店員掃描
- **有效期限**：設定到期日，30 天內到期／已過期會在卡片上標示
- **排序**：智慧（常用＋最近）、使用次數、名稱、新增時間、到期日
- **綁定會員 App**：不能截圖的會員條碼（App 禁止截圖），一次勾選多個會員 App 綁定成卡片，點卡片直接開啟該 App 出示
- **資料夾分類**：自訂資料夾（超商、藥妝、餐廳…），首頁依資料夾分段顯示；長按卡片可移動、編輯、刪除；選單「管理資料夾」可改名、排序、刪除
- **從其他 App 分享匯入**：在店家 App 或其他會員卡 App 截圖／分享條碼 →選「加入會員卡夾」，自動辨識並建立卡片
- **連結店家 App**：卡片頁一鍵開啟店家 App（適合 OPENPOINT、PX Pay 這類動態條碼），在清單長按卡片也能直接開啟
- **主畫面捷徑**：卡片頁按「🏠」把卡片釘到桌面，一點就顯示條碼；長按 App 圖示也會列出最常用的 4 張
- **自動檢查更新**：開啟 App 時會檢查 GitHub Releases，有新版會跳出提示，可直接下載並安裝（選單也能手動「檢查更新」）
- 支援 Code 128、Code 39（手機條碼載具）、EAN-13/8、UPC-A/E、ITF、Codabar、Code 93、QR Code、PDF417、Data Matrix、Aztec，或只顯示號碼
- 常見店家快速帶入（7-ELEVEN、全家、全聯、家樂福、屈臣氏、康是美、星巴克、Costco、IKEA…）
- 顯示條碼時螢幕自動調到最亮並保持常亮
- 可設為「常用」置頂，其餘依最近使用排序；可搜尋店家、號碼、備註
- 自訂卡片顏色、備註
- 匯出／匯入 JSON 備份（換手機時使用），資料只存在手機本機

## 下載安裝

到 [Releases](../../releases) 下載最新的 `MemberCardWallet-x.y.z.apk`，在手機上開啟安裝（需允許「安裝未知來源應用程式」）。

## 開發

- Kotlin + Jetpack Compose（Material 3），minSdk 26（Android 8.0）
- 條碼產生／辨識：ZXing、zxing-android-embedded
- 推送到 `main` 時，GitHub Actions 會編譯、簽章並發布 Release（版本號在 `version.txt`，要出新版就改這個檔）

```bash
./gradlew assembleRelease
```

簽章金鑰放在 repo Secrets：`KEYSTORE_BASE64`、`KEYSTORE_PASSWORD`、`KEY_ALIAS`、`KEY_PASSWORD`。沒有設定時會使用 `app/signing/release.jks`（repo 內附金鑰）簽章。
